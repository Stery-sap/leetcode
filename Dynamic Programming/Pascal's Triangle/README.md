# Two Sum

- **LeetCode:** [#118 - Pascal's Triangle](https://leetcode.com/problems/pascals-triangle/)
- **Pattern:** Dynamic Programming
- **Difficulty:** Easy
- **Language:** Python

## Problem

Given an integer numRows, return the first numRows of Pascal's triangle.

## Approach

This solution uses an iterative dynamic programming approach to generate Pascal's Triangle row by row, leveraging padding to simplify the addition of adjacent elements.

## Complexity

- **Time:** O(n^2)
- **Space:** O(n^2)
